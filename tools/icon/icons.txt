# The name -> picture mapping, and the only place a wrong icon can be introduced.
#
# Every icon the app draws is listed here by the job it does, not by a number. `build-icons.ps1`
# fetches each one from Fluent UI System Icons (MIT, github.com/microsoft/fluentui-system-icons) and
# writes src/BertBrowser.App/Resources/Icons.xaml. Call sites say Icon.Back; a name that is not in
# this file fails to load rather than drawing the wrong thing.
#
# Why not the Segoe Fluent Icons font, which this replaced:
#   - a call site was a bare codepoint, so nothing could tell E76E (a smiley face) from a split-pane
#     button, and four wrong pictures shipped: E76F and E76E on the pane buttons, E8B0 (a mouse
#     cursor) on "Open in new pane", E74B (a down arrow) on "Delete permanently".
#   - the font is Windows 11 only. Windows 10 falls back to Segoe MDL2 Assets, where some of those
#     codepoints are simply absent and render as tofu.
#   - Segoe is licensed for use on Windows, not for redistribution, so its outlines could not be
#     bundled to fix that.
#
# Format: Name | Fluent asset folder | file stem | size. Size picks the artwork's own grid; 20 is
# the one drawn for small UI. To change a picture, change its line here and re-run the script —
# never edit Icons.xaml by hand.
